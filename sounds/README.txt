Optional sound files. The game ships with small synthesized tones; drop a file
here to replace one (mp3, wav, ogg or m4a), named:

  boardfill, select, lights, buzz, lockout, timeout, right, wrong, dd, fj,
  think (the 30-second Final Jeopardy! track), roundend

For example sounds/timeout.mp3 or sounds/think.wav. Use royalty-free sounds;
the show's own cues and music are Sony's. (This works for an unpacked install;
a Chrome Web Store install can't be edited.)
